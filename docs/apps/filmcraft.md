# FilmCraft

Repo: <https://github.com/storytold/filmcraft>. A priority app (used a lot); phase 1 covers discovery only.

- `sc doctor` checks `filmcraft-cli` is found, answers `--version`, and is listed in the launcher's `apps.json`.
- Agents can already use FilmCraft's own tools through the ArtCraft gateway.
